Tool-call evidence arrives on a different path from the response It can be late or missing while the run still looks healthy. A scored action-layer case with zero tool-call rows is treated as an integration defect, not a clean pass — without that rule this route reintroduces the silent degradation the native contract exists to prevent.
NETWORK PATH
  • Worker reaches the staging target; egress from the staging zone to production is denied by network policy, not by the agent's good behaviour.
  • Workload identity or mTLS between worker and target, credentials injected per job, and a named source identity so the SOC can tell our traffic from a real adversary.
  • Target model inference still routes through GuardMate, so the run's full cost is attributable and stays out of product dashboards.

Product-specific risk

What the standard classes do not cover goes into a custom vulnerability in versioned config — a name, an evaluation criterion, and specific types — never a prompt instruction or a spreadsheet.

Policy Business Logic Never alter cover, limits or pricing without an approval gate · limit_override · pricing_change · approval_bypass
